# Targeting Course Sources

This course uses these public sources as its platform-grounded reference set:

1. Meta Blueprint, “Introduction to advertising courses for Facebook and Instagram”
   https://www.facebook.com/business/learn/courses/advertising/
   - Campaign objectives, audiences, Ads Manager, testing, measurement, placements, policy and account safety.
2. Meta, “Get started with Conversions API”
   https://www.facebook.com/business/learn/video/get-started-conversions-api/
   - Pixel plus Conversions API as measurement signals for optimization.
3. Google Ads Help, “About conversion measurement”
   https://support.google.com/google-ads/answer/1722022?hl=en
   - Valuable conversion actions, conversion values, CRM/offline conversions, learning phase, consent and diagnostic setup.
4. Google Ads Help, “Use data to optimize your Search campaigns”
   https://support.google.com/google-ads/answer/9451527?hl=en
   - Search metrics and optimization from user interaction through conversion.
5. CXL Institute course catalog
   https://cxl.com/institute/
   - Independent curriculum coverage for positioning, voice-of-customer research, CRO, analytics, GTM, experimentation, Meta and Google Ads.

## How sources are used

Platform documentation changes often. The course teaches durable decision models first and treats each platform’s interface as an implementation layer. Before any live launch, re-check the relevant Meta or Google documentation, current advertising policies, consent rules and measurement setup instructions.

The course does not promise results or instruct spending money. Any paid test requires a separate business decision, a defined budget, consent-compliant tracking and an operational lead-response process.
